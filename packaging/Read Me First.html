Koe声

Speak.
It's written.

Koe (声, “voice”) turns what you say into clean text wherever your cursor is: Slack, mail, docs, code. Everything runs on your Mac. Setup takes about five minutes, plus a one-time model download.

Install

  1. Drag Koe into Applications

    In this window, drag Koe onto the Applications folder. Requires an Apple Silicon Mac on macOS 14 or later.

  2. Open it once from System Settings

    Open Koe from Applications. Because it isn't from the App Store, macOS stops it the first time: click Done.

    Then open System Settings → Privacy & Security, scroll down, click Open Anyway next to Koe, and confirm. You only do this once.

  3. Flip three switches

    Koe's setup screen asks for Accessibility (to type for you and see the fn key) and Microphone. Input Monitoring is optional.

  4. Download the models

    In Koe, open Models and click Download on Balanced (5.9 GB). Choose Max (20 GB) instead if your Mac has 32 GB of memory or more.

    A Terminal window shows the download; every file is checked against a pinned fingerprint before it's installed. When it's done, click Restart now.

  5. Talk

    Hold fn, speak, let go. Or press ⌘ ⇧ Space to start and again to stop (change it in Settings). Add names and jargon under Dictionary.

Private by design
  • Speech recognition and cleanup run entirely on your Mac. Koe has no network code at all.
  • What you dictate is never saved to disk or written to logs.
  • Pasted text is kept off Universal Clipboard and out of clipboard managers.
  • Models come from their makers' official pages, and each one is verified before it loads.

If macOS says Koe “is damaged and can't be opened”, run this once in Terminal, then open it again:
xattr -dr com.apple.quarantine /Applications/Koe.app
